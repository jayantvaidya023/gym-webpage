# BURN GYM - Official Website (Phase 9, Mohali)

A complete, premium, modern website for **BURN GYM**, featuring a bold cinematic dark theme with black backgrounds, white typography, and striking red accents, built for high athletic visual impact.

## 🌟 Highlights
- **Cinematic Logo Animation**: Seamless opening intro video featuring the official BURN GYM 3D logo reveal with sound toggle, real-time progress bar, and "Skip Intro" option.
- **Brand Identity**: Authentic transparent BURN GYM logo integrated across all sections.
- **Hero & 4 Pillars**: Full-screen visual opening with live gym status, dual CTAs ("Book A Free Trial Pass" & "Explore Membership"), and the 4 Core Athletic Pillars.
- **Accurate Mohali Phase 9 Info**:
  - **Location**: Punjab Olympic Association Building, Opp. House No. 714, Backside of Sports Complex, Phase 9, SAS Nagar, Mohali, Punjab 160062.
  - **Timings**: Mon–Sat: 5:00 AM – 11:00 PM | Sun: 7:00 AM – 7:00 PM.
  - **Reception & WhatsApp**: +91 97819 90011 / 0172-5010106.
- **Interactive Tools**:
  - **BMI & Calorie / Protein Calculator**: Computes BMI, maintenance calories (TDEE), and goal-adjusted protein intake with a 1-click WhatsApp sync to coaches.
  - **Transformation Lightbox**: Interactive categorized photo gallery with full-screen zoom modal.
  - **Trial Pass Reservation**: Functional booking form with validation, celebratory confetti, and WhatsApp auto-sync.

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS with custom athletic glow utilities
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti, CSS Keyframe animations

## 🚀 Running Locally
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
